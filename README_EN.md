# 🌍 AFRINTEL Cyber Incident Intelligence

AFRINTEL is an open‑source **Cyber Threat Intelligence (CTI)** initiative dedicated to tracking and analysing cyber attacks affecting African organizations.

Reports rely on monitoring:

- ransomware leak sites
- underground cybercrime forums
- public OSINT sources
