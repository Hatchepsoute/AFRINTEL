# Rapport AFRINTEL sur les cybermenaces - S1 2026

Du 1er janvier au 30 juin 2026, AFRINTEL recense **304 incidents ou cas documentés** dans le corpus mensuel validé.

| Type | Nombre | Part |

| Fuite de données | 126 | 41.4% |
| Ransomware | 116 | 38.2% |

## Méthodologie

Les chiffres sont calculés depuis les fiches françaises, contrôlés contre les fiches anglaises, puis réutilisés dans les comparaisons et STIX. Le rattachement mensuel suit la publication ou la première observation documentée ; aucune date de compromission n est déduite.
