# AFRINTEL Visual Intelligence - Avril 2026

👉🏾 [English version](./README.md)

## Objectif

Ce dossier fournit une lecture visuelle des incidents cyber observés par AFRINTEL en avril 2026.

Les visualisations reposent sur les statistiques consolidées suivantes :

- **60 incidents** au total
- **20 attaques ransomware**
- **40 fuites de données / ventes d’accès**
- **16 pays touchés**
- **30+ acteurs distincts**

## Note méthodologique

Les incidents issus de forums cybercriminels, leak sites ou canaux underground sont traités comme des revendications tant qu’ils ne sont pas confirmés indépendamment.
