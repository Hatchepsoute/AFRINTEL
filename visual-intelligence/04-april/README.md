# AFRINTEL Visual Intelligence — April 2026

👉🏾 [Version française](./README_FR.md)

## Objective

This directory provides a visual intelligence view of cyber incidents monitored by AFRINTEL in April 2026.

The visualizations are based on the following consolidated statistics:

- **60 total incidents**
- **20 ransomware attacks**
- **40 data leaks / access sales**
- **16 affected countries**
- **30+ distinct threat actors**

## Available Files

| File | Description |
|---|---|
| `ecosystem-map_april_2026.md` | Actor → Country → Sector relationship map |
| `country-hotspots_april_2026.md` | Visual ranking of most affected countries |
| `sector-map_april_2026.md` | Sector distribution |
| `ransomware-vs-leaks_april_2026.md` | Ransomware vs data leaks comparison |
| `actors_april_2026.md` | Most active threat actors |

## Methodology Note

Incidents observed on cybercriminal forums, leak sites, or underground channels are treated as claims unless independently confirmed.
