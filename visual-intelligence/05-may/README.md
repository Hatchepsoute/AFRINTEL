# AFRINTEL visual intelligence - May 2026

👉🏾 [Version française](./README_FR.md)

## Objective

This directory provides a visual intelligence view of cyber incidents monitored by AFRINTEL in May 2026.

The visualizations are based on the following consolidated statistics:

- **54 total incidents**
- **16 ransomware attacks**
- **38 data leaks / access sales**
- **11 countries affected + multi-country incidents**
- **25+ distinct threat actors**

## Available files

| File | Description |
|---|---|
| `ecosystem-map_may_2026.md` | Actor → Country → Sector relationship map |
| `country-hotspots_may_2026.md` | Visual ranking of most affected countries |
| `sector-map_may_2026.md` | Sector distribution |
| `ransomware-vs-leaks_may_2026.md` | Ransomware vs data leaks comparison |
| `actors_may_2026.md` | Most active threat actors |

## Methodology note

Incidents observed on cybercriminal forums, leak sites, or underground channels are treated as claims unless independently confirmed.
